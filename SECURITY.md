# Security policy

Please report vulnerabilities privately through [GitHub's private reporting](https://github.com/paodo-solution/PAODO-Workspaces/security/advisories/new), never in a public issue. Include the affected version or commit, the steps to reproduce, and the impact you observed.

Only the latest release receives security fixes. What PAODO does and does not defend against is described in [doc/security_notes.md](doc/security_notes.md).
